# Library Management System

A full-stack library management application built with Node.js and React to manage books, physical copies, library members, borrowing, and returns.

> **Project status:** Planning and setup  
> **Project classification:** Small MVP

## Tech Stack

- **Frontend:** React
- **Backend:** Node.js
- **Database:** PostgreSQL

## Core MVP Features

1. Book and author management
2. Member management
3. Physical-copy availability tracking
4. Issue and return books
5. Due dates and overdue tracking
6. Borrowing history

These are proposed MVP features and will be finalized during the requirements phase.

## Project Structure

The frontend and backend structure will be established during their respective setup phases.

## Development Workflow

This project follows the supplied project playbook and Git workflow conventions.

- Use Conventional Commits.
- Push feature branches and submit pull requests.
- Merge pull requests using **Create a merge commit**.

## Setup

Development setup instructions will be added as the application structure and configuration are established.

## Scope

This MVP prioritizes core library operations. Advanced reporting, notifications, fines, reservations, and deployment infrastructure are outside the initial scope unless explicitly approved later.
